# 회의록

> 출처: Notion 「회의록」 (마지막 수정: 2026-11-10)

회의록은 팀 회의에서 논의한 내용, 결정 사항, 할 일, 다음 회의 일정을 기록하는 문서이다.

회의 내용을 기록하지 않으면 나중에 “그때 어떻게 정했지?”라는 문제가 생길 수 있으므로, 짧게라도 꾸준히 작성한다.

## 회의록 작성 시 주의사항

- 모든 대화를 자세히 적기보다 결정 사항과 할 일을 중심으로 작성한다.
- 결정되지 않은 내용은 “논의 필요”로 남긴다.
- 회의가 짧더라도 날짜별로 꾸준히 기록한다.
