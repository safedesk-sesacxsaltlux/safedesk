# 완료 기준 체크리스트

> 「다 됐다」의 기준이다. D4(11/16) 화면 연동 확인, D6(11/18) 통합 테스트, D7(11/19) 리허설에 이 표를 그대로 쓴다.
> 각 항목은 **배포 서버에서, 화면으로** 확인한다. Postman으로만 확인한 것은 통과가 아니다.
> 실패하면 GitHub Issue(버그)로 올리고 이슈 번호를 결과 칸에 적는다.

## 준비

| 확인 | 내용 | 담당 |
| --- | --- | --- |
| ☐ | 배포 서버에서 프론트·백엔드·DB가 뜬다 | 유능한 |
| ☐ | `schema.sql`로 만든 테이블에서 백엔드가 시작된다 (`ddl-auto: validate`) | 유능한 |
| ☐ | 시드 데이터: 상담원 2명, 관리자 1명, FAQ 30건, 금칙어, 정책 기본값 | 유능한, 심소민, 한수민 |
| ☐ | 시연용 고객 계정 2개 (위반 0회, 위반 1회) | 유능한 |
| ☐ | AI 목업 모드가 `NORMAL`이다 | 심소민 |
