## 문서를 바꿀 때

- 코드와 같은 PR에서 문서도 고친다. 리뷰어가 둘을 같이 본다.
- `contract.md`의 값, 다른 사람 API 문서는 혼자 바꾸지 않는다. 「확정 필요」에 올리고 Daily Scrum에서 정한다.
- 역할 분담·일정·진행 상태는 노션 WBS와 GitHub Issues에서 관리한다. 여기 두지 않는다.
