### 시연 시나리오

| 순서 | 화면 | 시연 내용 | 확인할 점 |
| --- | --- | --- | --- |
| 1 | 메인 페이지 | 서비스에 접속한다. | 서비스명과 주요 메뉴가 보인다. |
| 2 | 회원가입 페이지 | 새 계정으로 회원가입한다. | 회원가입이 성공한다. |
| 3 | 로그인 페이지 | 가입한 계정으로 로그인한다. | 로그인 상태로 전환된다. |
| 4 | 스터디 목록 페이지 | 스터디 목록을 조회한다. | 모집글 목록이 표시된다. |
| 5 | 스터디 상세 페이지 | 스터디 상세 내용을 확인한다. | 제목, 설명, 모집 상태가 표시된다. |
| 6 | 스터디 신청 | 스터디 신청 버튼을 클릭한다. | 신청 완료 메시지가 표시된다. |
| 7 | 마이페이지 | 신청 내역을 확인한다. | 신청한 스터디가 목록에 표시된다. |
| 8 | 스터디 등록 페이지 | 새 스터디 모집글을 등록한다. | 등록한 글의 상세 페이지로 이동한다. |
