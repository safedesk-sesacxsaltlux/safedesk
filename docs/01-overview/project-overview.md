# 프로젝트 개요서

> 출처: Notion 「프로젝트 개요서」 (마지막 수정: 2026-11-09)

### 프로젝트명

세이프데스크 (SafeDesk, 가칭)

### 서비스 한 줄 소개

AI가 먼저 응대하고, 상담원 연결 후에는 폭언을 자동으로 걸러 경고·종료·이용정지까지 처리해 상담사를 보호하는 AICC 채팅 상담 플랫폼

### 기획 배경

AICC가 도입된 뒤 AI 상담에서 쌓인 불만이 사람 상담사에게 넘어간다. 한국노총 조사에서 시민 54.2%가 AICC에 불만족했고, 87.5%는 사람 상담사를 선호했으며, 도입 후 일평균 민원은 17.9% 늘었다(뉴시스, 2026-01-22). 명확한 대응 규칙은 효과가 있다. 120다산콜은 특이민원을 악성·강성·주의로 나누고 맞춤 스크립트를 도입한 뒤 악성 민원이 전년 대비 50% 넘게 줄었다(YTN). 관세청은 언어폭력·성희롱 시 1회 7일, 2회 30일 이용정지를 두는 훈령 개정을 예고했다(세정일보). 하지만 이런 규칙을 적용하는 건 여전히 사람의 손이다. 상담사는 폭언을 끝까지 들은 뒤 직접 경고·종료 버튼을 눌러야 하고, 제재 기준은 상담사와 관리자마다 다르게 적용된다. 기존 서비스는 폭언 감지나 순화에서 멈추고, 위반자 제재까지 이어지지 않는다. 세이프데스크는 감지 → 경고 → 종료 → 제재를 시스템이 한 흐름으로, 일관되게 처리하도록 만든다.

### 기대 효과

상담사는 폭언 원문 대신 욕설을 가린 문장을 보며 상담하므로, 악성 민원에 직접 노출되는 일이 줄어든다. 경고와 강제 종료를 시스템이 자동으로 처리해, 상담사가 직접 판단하고 대응해야 하는 부담이 없어진다. 고객별 위반 이력을 누적해 제재를 일관된 기준으로 적용하므로, 사람마다 달랐던 대응 기준이 통일된다. 폭언 원문은 별도로 저장해 법적 대응의 근거로 남긴다. 단순 문의는 AI가 먼저 처리하고 필요한 경우에만 상담원에게 연결해, 상담 인력을 효율적으로 쓸 수 있다. 결과적으로 AICC 환경에서도 상담사가 안전하게 일할 수 있는 상담 운영 구조를 만든다.

### 주요 사용자

```txt
- 고객: 120 다산콜센터 챗봇으로 민원 접수하는 사람
- 상담원: 대기열에서 상담을 수락하고, 욕설을 가린 메시지로 실시간 상담을 진행하는 사람
- 관리자: 제재 정책을 설정하고, 제재 고객·상담 이력·통계를 관리하는 고객센터 운영자
```

### 핵심 기능

```txt
• 회원가입 / 로그인 (고객·상담원·관리자 역할 구분)
• 고객 채팅 상담 + AI 1차 응대 (AI 실패 시 FAQ 키워드 답변)
• 상담원 연결 요청 / 상담 대기열 조회 / 상담 수락
• 상담원과 고객 간 실시간 채팅 상담
• 폭언 감지
• 상담원 화면 욕설 마스킹 (원문은 별도 저장)
• 고객 경고 자동 발송 / 반복 위반 시 상담 자동 종료
• 위반 누적에 따른 자동 이용정지 (제재 정책 엔진)
• 이용정지 고객 입장 시 정지 안내 및 해제 일자 표시
• 관리자 제재 정책 설정 / 제재 고객 조회·해제
• 상담 종료 시 요약 저장 / 상담 이력 조회
• 상담·위반 통계 대시보드
```
