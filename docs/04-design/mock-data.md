- 가공 이유 및 방법

  원천 데이터를 그대로 쓰지 않음. **내용은 데이터에서만 가져왔고, 문장은 Claude가 재가공.**
  원천이 FAQ가 아니라 고객과 상담사가 여러 턴 주고받은 **대화 기록**이라서, 그대로는 FAQ로 쓸 수 없었음

- 가공 방법:
  1. **주제 선정:** 대화 수가 많고 매번 같은 답이 나오는 주제 선택
  2. **질문:** 대화 속 고객 발화를 대표 질문 1문장으로 다듬음
  3. **답변:** 1~2개 대화에 흩어진 상담사 답변을 모아 2~3문장으로 재작성
  4. **삭제:** 가려진 정보(OOO)와 데이터끼리 모순되는 내용 제거
  5. **키워드:** 원천에는 키워드가 없어서 새로 작성

### 1. 개요

| 항목 | 내용 |
| --- | --- |
| 용도 | 1차 응대: 키워드로 FAQ를 찾아 답하고, 못 찾으면 상담원 연결 |
| 원천 | [AI Hub「민원(콜센터) 질의응답」 다산콜센터 (2020년 구축)](https://aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&aihubDataSe=data&dataSetSn=98) |
| 가공 | 상담 대화에서 고객 질문을 대표 질문으로 다듬고, 같은 주제 대화 1~2건의 상담사 답변을 요약·재작성함(Claude 활용). 원천에 없는 내용은 추가하지 않음 |
| 건수 | 30건 |

### 2. `faq_seed.csv`

| 컬럼 | ERD | 설명 | 예시 |
| --- | --- | --- | --- |
| `faq_id` | FAQ ID | 1~30 | `1` |
| `category` | 문의 유형 | 상하수도(1~9) / 일반행정(10~21) / 대중교통(22~30) | `상하수도` |
| `question` | 질문 | 대표 질문 | `수도요금 납부 방법이 어떻게 됩니까?` |
| `answer` | 답변 | 고객에게 보여줄 답변 | `청구서, 자동납부, ...` |
| `keywords` | 매칭 키워드 | 쉼표 구분 | `납부방법,요금납부,편의점` |

### 3. 매칭 규칙

1. 질문의 공백을 지운다.
2. 질문에 포함된 키워드의 글자 수 합이 가장 큰 FAQ를 고른다.
3. 점수가 0이면 상담원 연결로 넘긴다.
